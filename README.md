# Corcoran_et_al_2026_CellReports
ImageJ/FIJI macros from Corcoran et al. (2026) "Exosome secretion is required for Sonic Hedgehog dispersal and signal gradient formation in the embryonic limb bud mesenchyme" Cell Reports

Overview:
In Corcoran et al., 2026, there are two ImageJ/FIJI macros that were used for data analysis. 

The first macro, CDHrelease_Kinetics_Macro.ijm, is used to quantify the fluorescence intensity of Shh-CB-msfGFP in the Golgi apparatus to determine the kinetics of a CDH-based synchronous release. This macro could also be used to determine the kinetics of Retention using selective hooks (RUSH) based releases. Original core of the code was written by Christine Labno and Fernando Valbuena and modified by Sean Corcoran.

The second macro, LimbBudGradientAnalysisFinal.ijm, is used to measure the radial fluorescence intensity of immunofluorescently stained Shh emanating from the zone of polarizing activity in dissected limb buds. This code was written by Sean Corcoran.

Prerequisites and Installation:
To run these macros you will need Fiji/ImageJ. You can download it from fiji.sc.
